# Live check — try it in a browser before "let me test"

Runs at workflow step 4 when the change is something I open in a browser (a site, a web app). Skip it for things with no page (a bot, a script).

1. Use whatever browser tool you have (your tool's built-in browser, Playwright, or similar). Don't install one just for this.
2. Start the project the way "Nasıl açılır" says and open it.
3. Do the task's "bitti sayılır" steps for real: click, type, submit. Also check that nothing on the page is obviously broken (errors in the console, blank areas, broken layout).
4. Tell me in one plain line what you tried and what you saw. Show a screenshot if you can.
5. If something is wrong, fix it before handing it to me.
6. No browser tool, or it couldn't open the page: say plainly "Tarayıcıda bakamadım" and why. Never say it works if you didn't see it.

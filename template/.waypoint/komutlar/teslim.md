1. If it's something I open (an app, a site, a bot), it needs a double-click launcher (Windows: `baslat.bat`, macOS: `baslat.command`), listed first in "Nasıl açılır" in `ILERLEME.md`; terminal commands are only a fallback. Keep "Nasıl açılır" up to date whenever how to start the project changes.
2. Try it yourself first, started the way I will start it: really run the launcher and see the project come up, not your own command. If it opens in a browser, also follow `canli-kontrol.md`.
3. Tell me honestly what you checked and what you couldn't, then how I can try it, step by step. It's not done until I say it works.

## Close

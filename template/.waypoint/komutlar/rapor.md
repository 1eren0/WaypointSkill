# Research and reports

Read this before you research something and when you write a report.

1. Before researching, pick the related reports in `.waypoint/raporlar/` by file name and read only their summaries; open a full report only if needed. Reuse what's there; research only what's missing, and re-check a finding if it's old or the project now uses other versions.
2. A report goes in `.waypoint/raporlar/` as `YYYY-AA-GG-<konu>.md` (several files: a `YYYY-AA-GG-<konu>/` folder starting with `ozet.md`), with a one-line "Günlük" entry in `ILERLEME.md` naming it.
3. Start each report with five short lines: `Bulgu:`, `Kanıt:` (with the versions it applies to), `Alternatif:`, `Belirsiz:`, `Kaynaklar:`.
4. A sub-agent that researched something writes a report and hands you its summary and path, not the whole text.
